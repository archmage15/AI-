还原度测试 · 目录说明
================================================

你只需要记住两个文件夹：audio（放录音）、output（看结果）。

  audio\      放录音
              原音频.*     = 原声（跟读的那段）
              模仿.*       = 你的跟读
              扩展名随意：mp3 / wav / flac / ogg 都认（m4a、aac 不行）
              优先级 mp3 > wav > flac > ogg（同名多个时取第一个）
              ⚠ mp3 是有损的，分要求高就用 wav，或 mp3 码率 >= 192kbps
              （长音频模式还会自动生成/读取：转写文本.txt、参考音素.json）

  output\     看结果（脚本自动生成，每次跑覆盖，可随时清空）
              还原度综合报告.txt   ← 这份是给人看的，先看它
              音素对比_报告.txt    ← 发音/音变明细（长音频这里是逐句明细）
              节奏对比.png         ← 两条曲线叠着看
              各种 .json           ← 给程序读的，不用管

  scripts\    程序都在这，不用进去（入口是 run_all.py，由 bat 自动调）
  models\     音素模型（1.2GB），不用进去。删了会自动重下。

怎么跑
------------------------------------------------
两个 bat 跑的是同一套流程，按你的场景选一个双击即可：

  · 「长文本模式一键跑还原度.bat」→ 适合测整段对话
  · 「单句模式一键跑还原度.bat」→ 适合一句一句练

两个都走：讯飞转写台词 → 按标点切句 → 逐句评测 → 综合分。
单句 = 你放的是一句话，切出来恰好 1 句，逐句评测自然只跑 1 次。
不用记命令。结果自动出现在 output\ 里。

改完代码先跑自检
------------------------------------------------
    python scripts\selftest.py

约 1 秒跑完（纯计算，不加载模型/音频，不会动 output\ 里的结果）。

什么时候跑：改完 scripts\ 下任何 .py 之后，跑一遍再跑正式评测。
它验的是「评分口径有没有被改坏」——这类问题不会崩，只会安静地算出一个
没意义的数。历史上踩过的几个静默错误都是这个形态：报告里留着上一次的旧图、
陈旧数据混进长音频报告、单句 63.2 和长音频 67.2 混着比写出「↑+4.0」假进步。

58 个用例，每个都锚定一次真实踩过的坑：
  1. 半截检测（10-16 漏头用 delete 段抓不到的坑）
  2. 节奏分（09-28 归一化 + 幂平均 p=3）
  3. 停顿判定（换人处的停顿不算停顿错误）
  4. 词级错误（09-23 基准=原音频实际音素）
  5. 长音频逐句分配、漏句与碎句判定
  6. 综合分公式与等级
  7. history 跨模式隔离（P1 假进步）

退出码 0 = 全过，1 = 有失败（会打印期望值 vs 实际值）。

长文本模式说明（「长文本模式一键跑还原度.bat」）
------------------------------------------------
长文本会先要一句「台词文本」当参照，**每次都会调讯飞转写当真值**：
  1. 根目录有 讯飞配置.json → 自动调讯飞把原音频转写成文字
     （格式：{"app_id":"你的APPID","secret_key":"你的SecretKey"}，不会被 git 提交）
  2. 没有 讯飞配置.json 或转写结果为空 → 报「没识别到文本」直接退出

拿到文本后：按标点切句 → 模仿音频按「内容」对齐到每一句 → 逐句评测
→ 没读到的句子判「漏句」不计分 → 汇总成一个综合分。

※ 只模仿了前半段？自动识别，只按读到的部分算分，未读句子单独列出。
※ 全程不用录音时间戳对齐（讯飞时间戳误差 150ms+，不可靠），
  按「说了什么」对齐，所以读快读慢、跳句、半截都不会错位。

怎么换句子（换素材）
------------------------------------------------
不管是单句还是长文本，都只换两个音频文件就行：
1. audio\原音频.*
2. audio\模仿.*
   （台词文本每次都会自动重新转写、参考音素表自动重生成，不用手动管）

最后双击对应的 bat（长文本 / 单句）。

第一次跑之前的准备
------------------------------------------------
如果还没装依赖：双击本目录的 install_deps.bat

常见问题
------------------------------------------------
Q: 双击 bat 一闪就没了？
A: 说明没找到可用的 Python。先双击 install_deps.bat 装依赖。

Q: 报错说缺 原音频 / 模仿？
A: 检查 audio\ 里的文件名是不是精确叫这两个（扩展名随意），注意别多了空格。
   支持 mp3 / wav / flac / ogg；m4a、aac 不支持，要用这两种先转成 mp3。

Q: 长文本报错说「没识别到文本」？
A: 见上面「长文本模式说明」：在根目录放 讯飞配置.json（自动转写），
   并确认音频里确实有人声。转写失败也可能是网络问题或钥匙无效。

Q: output\ 里的东西能删吗？
A: 能。那是每次跑的产物，重跑一次就回来了。

Q: models\ 太大了想删？
A: 可以删。下次跑会自动重新下载（约 1.2GB，较慢）。

Q: 想发给别人？
A: 别发 .venv\（几百 MB，路径绑死本机）、models\ 里的
   pytorch_model.bin（1.2GB，会自动重下）、讯飞配置.json（含密钥）。
   发 scripts\ + 长文本模式一键跑还原度.bat + 单句模式一键跑还原度.bat
   + install_deps.bat + requirements.txt 就够了。
